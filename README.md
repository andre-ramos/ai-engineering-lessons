# ai-engineering-lessons

This a repo for training exercises on the AI Engineering Roadmap

## Lesson folders

- [MCP](./mcp): Implementation of a MCP project with client and server using FastMCP in Python from https://anthropic.skilljar.com/introduction-to-model-context-protocol

- [Agents](./agents): Implementation of different agent architectures in Python using Langchain/LangGraph/Pydantic from https://github.com/NirDiamant/GenAI_Agents

- [RAG](./rag): Implementation of different RAG architectures/patterns in Python using Langchain/LangGraph/Pydantic from https://github.com/NirDiamant/RAG_Techniques/tree/main
